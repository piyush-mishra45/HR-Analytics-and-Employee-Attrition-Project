# Setup & Execution Guide (Windows 11 + VS Code)

## 1. Install prerequisites
| Tool | Where | Notes |
|---|---|---|
| Python 3.12+ | python.org/downloads | Tick **Add python.exe to PATH** |
| Git | git-scm.com | |
| VS Code | code.visualstudio.com | Extensions: *Python*, *Jupyter*, *SQLTools* (+ MySQL driver) or *MySQL Shell for VS Code* |
| MySQL 8.0 + Workbench | dev.mysql.com/downloads/installer | Remember the root password |
| Power BI Desktop | Microsoft Store | Windows only |
| Excel (2019 / 365) | | Needed only to open the workbook |

## 2. Get the project and create a virtual environment (PowerShell)
```powershell
cd HR_Analytics_Attrition_Project
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1          # if blocked: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
python -m pip install --upgrade pip
pip install -r requirements.txt
```
In VS Code: `Ctrl+Shift+P` -> **Python: Select Interpreter** -> pick `.venv`.

## 3. Run the full analysis pipeline
```powershell
python python/run_pipeline.py
```
It cleans the data, writes tables, 17 figures, `sql/insert_data.sql`, validates the SQL, rebuilds the Excel workbook, the PDF and the notebooks. You can also run the steps one at a time:
```powershell
python python/data_cleaning.py
python python/eda_analysis.py
python python/visualization.py
```

## 4. Notebooks
Open `notebooks/01_Data_Exploration.ipynb` in VS Code, choose the `.venv` kernel and **Run All**. Run them in order 01 -> 04. (Notebooks ship without saved outputs.)

## 5. MySQL database
Open **MySQL Command Line Client** (or Workbench) from the project folder:
```sql
SOURCE sql/create_database.sql;
SOURCE sql/create_tables.sql;
SOURCE sql/insert_data.sql;
SOURCE sql/analysis_queries.sql;
```
(In the Windows client use forward slashes in the path, e.g. `SOURCE C:/path/to/project/sql/create_tables.sql;`.)
Expected after loading: 1,470 rows in `employees`, `employee_satisfaction`, `attrition_analysis`; 3 departments; 9 job roles.

## 6. Excel
Open `excel/HR_Analytics_Report.xlsx` (starts on **KPI_Summary**). Every analysis number is a formula over `Cleaned_Data`.
**Adding true PivotTables** (the workbook uses formula-driven summary tables because PivotTables cannot be generated by script):
1. Click inside `Cleaned_Data` -> **Insert -> PivotTable** -> new sheet.
2. Rows: `Department`; Values: `Count of EmployeeNumber`, `Sum of AttritionFlag`; right-click the sum -> **Show Values As -> % of Column Total** or add a calculated field `AttritionFlag/EmployeeNumber`.
3. **PivotTable Analyze -> PivotChart** for a pivot chart.

## 7. Streamlit dashboard
```powershell
streamlit run dashboard/app.py
```
Opens http://localhost:8501. Use the bundled sample or upload the raw/cleaned CSV.

## 8. Power BI
Follow `powerbi/POWERBI_BUILD_GUIDE.md`. The `.pbix` is not shipped - you build it from the supplied cleaned CSV, DAX and theme.

## 9. Git / GitHub

```powershell
git init
git add .
git commit -m "HR attrition analytics project"
git branch -M main
git remote add origin https://github.com/<you>/HR_Analytics_Attrition_Project.git
git push -u origin main
```

## Troubleshooting
- **`ModuleNotFoundError: config`** - run scripts as `python python/<script>.py` from the project root. Notebooks find the project root automatically.
- **Garbled first column `ï»¿Age`** - read the CSV with `encoding="utf-8-sig"` (all project code already does).
- **MySQL `ERROR 1046 No database selected`** - run `create_database.sql` first (it ends with `USE hr_analytics_db;`).
